# 初中历史复习全景时间线项目方案

### 1. 项目名称与整体说明
*   **项目名称**：初中历史复习全景时间线 (Junior High History Review Timeline)
*   **整体说明**：本网站专为初中生设计，旨在通过直观的**垂直滚动时间线**，将繁杂的历史知识点串联起来。网站采用沉稳的学术配色，支持电脑与手机双端访问，核心功能是通过点击交互，深度展示历史事件的背景、意义及中考核心考点。

### 2. 技术栈
*   **HTML5**：构建语义化的页面结构。
*   **CSS3**：负责沉稳的视觉风格（蓝灰配色）、响应式布局（Flex/Grid）及平滑的展开收起动画。
*   **Vanilla JavaScript (ES6+)**：负责数据渲染、滚动监听及交互逻辑，不依赖任何第三方框架。

### 3. 项目文件结构
```text
/project-root
│
├── index.html          # 主入口文件，包含页面结构
├── css/
│   └── style.css       # 全局样式与时间线动画设计
├── js/
│   ├── main.js         # 页面逻辑、交互控制
│   └── data.js         # 历史事件数据库（由PPT内容转化而来）
└── assets/             # 存放图标、背景等静态资源
```

### 4. 页面整体布局说明
*   **顶部 (Header)**：固定标题栏，显示“初中历史复习全景时间线”及分类导航（古代史/近代史/现代史/世界史）。
*   **主体 (Main)**：
    *   **中央轴线**：页面中心有一条贯穿上下的垂直虚线/实线。
    *   **事件分布**：事件卡片沿轴线两侧交替排列（桌面端）或单侧排列（移动端）。
*   **底部 (Footer)**：简单的版权信息与复习进度提示。

### 5. 时间线功能设计
*   **垂直滚动**：用户通过向上滑动查看历史进程。
*   **吸附效果 (Sticky)**：当前的年份段（如“春秋战国”）在滚动到顶部时会短暂停留，提示当前所处历史时期。
*   **平滑导航**：支持通过侧边栏快速跳转到特定历史阶段。

### 6. 事件节点设计
*   **常态（收起）**：显示圆形节点、年份、事件标题。
*   **交互动画**：点击卡片后，卡片通过 `max-height` 或 `grid-template-rows` 配合 `transition` 实现平滑展开。
*   **展开内容**：
    *   **事件概述**：一句话简介。
    *   **历史意义/影响**：深度解析。
    *   **中考考点**：高亮显示 PPT 中的核心关键词（如：商鞅变法的影响）。

### 8. 后续接入 PPT 内容方式说明
*   **内容清洗**：将 ppt_content.txt 中的原始文本按 slide 分组，提取出“时间、事件、特征、影响”等关键信息。
*   **结构化映射**：手动或通过脚本将清洗后的文本填入 data.js 的对象模板中，确保每个 PPT 页面对应一个或多个时间轴节点。
